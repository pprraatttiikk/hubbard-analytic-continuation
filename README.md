# Hubbard Analytic Continuation

Research code for studying physics-specific learned priors for analytic
continuation in the one-dimensional Hubbard model.

## Research question

Can a neural analytic-continuation model trained on spectra generated by
tractable Hubbard systems learn a physical prior that generalizes to unseen
parameters, noise conditions, and larger systems?

## Project structure

- `src/hubbard_ac/physics/` — Hubbard model, exact diagonalization, spectra,
  and imaginary-time Green's functions
- `tests/` — physics and numerical validation tests
- `configs/` — reproducible experiment configurations
- `scripts/` — executable research workflows
- `notebooks/` — exploratory analysis only
- `data/` — generated datasets (not tracked by Git)
- `results/` — experimental outputs (not tracked by Git)
- `figures/` — publication figures
